# Real Data

Each `dataset_N` is one case study applying the methods validated in
`Simulations/` to a real archaeological dataset. Self-contained, same layout as
each `Simulations/Sim_*` folder: `data/`, `models/`, `scripts/`, `figures/`,
`output/`, `archive/`. See each dataset's own README for details.
